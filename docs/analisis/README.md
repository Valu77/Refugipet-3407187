# Análisis del Proyecto RefugiPet

## Descripción

Esta carpeta reúne la documentación de análisis del proyecto RefugiPet. Aquí se define el funcionamiento general del sistema, los procesos del negocio, la estructura de la información y los conceptos utilizados durante el desarrollo.

## Contenido

- **SRS.md:** Especificación de Requisitos del Software.
- **DiccionarioDatos.md:** Descripción de las entidades y atributos de la base de datos.
- **Glosario.md:** Definición de términos técnicos y del dominio del proyecto.

## Objetivo

Garantizar que todos los integrantes del equipo y las personas interesadas comprendan el funcionamiento del sistema antes de iniciar el desarrollo.
