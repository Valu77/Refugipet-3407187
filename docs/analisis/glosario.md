# Glosario

## API

Interfaz que permite la comunicación entre el frontend y el backend.

---

## Backend

Parte del sistema encargada de la lógica de negocio y acceso a la base de datos.

---

## Frontend

Interfaz gráfica con la que interactúa el usuario.

---

## PostgreSQL

Sistema gestor de bases de datos utilizado por RefugiPet.

---

## FastAPI

Framework de Python utilizado para desarrollar el backend.

---

## React

Biblioteca JavaScript utilizada para desarrollar la interfaz de usuario.

---

## CRUD

Operaciones de Crear, Leer, Actualizar y Eliminar información.

---

## Git

Sistema de control de versiones utilizado durante el desarrollo.

---

## GitHub

Plataforma donde se almacena el repositorio del proyecto.

---

## Refugio

Organización encargada de publicar mascotas para adopción.

---

## Adoptante

Usuario que solicita adoptar una mascota.

---

## Solicitud de adopción

Petición realizada por un usuario para adoptar una mascota registrada en la plataforma.
