# Criterios de Aceptación

## HU-001

- El usuario puede registrarse correctamente.
- El correo no puede repetirse.
- La contraseña debe ser obligatoria.

---

## HU-002

- El usuario podrá iniciar sesión con credenciales válidas.
- Se mostrará un mensaje cuando las credenciales sean incorrectas.

---

## HU-003

- El sistema mostrará todas las mascotas disponibles.
- Cada mascota mostrará fotografía e información.

---

## HU-004

- Los filtros deberán funcionar correctamente.
- Los resultados deberán actualizarse automáticamente.

---

## HU-005

- El usuario podrá enviar una solicitud.
- El refugio recibirá la solicitud.

---

## HU-006

- El refugio podrá registrar mascotas.
- La mascota aparecerá en el catálogo.

---

## HU-007

- El refugio podrá aprobar o rechazar solicitudes.
- El usuario será notificado.

---

## HU-008

- El administrador podrá gestionar usuarios.
- El administrador podrá gestionar refugios.
