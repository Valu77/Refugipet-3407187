# Requerimientos del Proyecto RefugiPet

## Descripción

Esta carpeta contiene toda la documentación relacionada con los requerimientos del sistema RefugiPet.

El objetivo es definir las funcionalidades que debe cumplir la plataforma, los requisitos de calidad, las historias de usuario, los criterios de aceptación y el Product Backlog del proyecto.

## Contenido

- RF.md → Requerimientos Funcionales.
- RNF.md → Requerimientos No Funcionales.
- HU.md → Historias de Usuario.
- CA.md → Criterios de Aceptación.
- Product Backlog.md → Lista priorizada de funcionalidades.

## Proyecto

**Nombre:** RefugiPet

**Descripción:**

RefugiPet es una plataforma web que centraliza el proceso de adopción de mascotas, permitiendo la interacción entre refugios y adoptantes mediante un sistema seguro y organizado.
