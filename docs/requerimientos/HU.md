# Historias de Usuario

## HU-001 Registro de usuario

Como usuario

Quiero registrarme en la plataforma

Para poder acceder a los servicios de adopción.

---

## HU-002 Inicio de sesión

Como usuario

Quiero iniciar sesión

Para acceder a mi cuenta.

---

## HU-003 Consultar mascotas

Como usuario

Quiero visualizar las mascotas disponibles

Para elegir cuál adoptar.

---

## HU-004 Buscar mascotas

Como usuario

Quiero aplicar filtros de búsqueda

Para encontrar mascotas que se ajusten a mis preferencias.

---

## HU-005 Solicitar adopción

Como usuario

Quiero enviar una solicitud

Para adoptar una mascota.

---

## HU-006 Registrar mascota

Como refugio

Quiero publicar una mascota

Para ponerla en adopción.

---

## HU-007 Gestionar solicitudes

Como refugio

Quiero aprobar o rechazar solicitudes

Para administrar correctamente el proceso de adopción.

---

## HU-008 Administrar plataforma

Como administrador

Quiero gestionar usuarios y refugios

Para mantener el correcto funcionamiento del sistema.
