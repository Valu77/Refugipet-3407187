# 📚 Documentación del Proyecto RefugiPet

Bienvenido a la documentación oficial del proyecto **RefugiPet**, una plataforma web desarrollada para centralizar y facilitar el proceso de adopción de mascotas entre refugios y personas interesadas en adoptar.

Esta carpeta reúne toda la información técnica, funcional y de planificación del proyecto, permitiendo comprender su funcionamiento, organización y desarrollo.
