# Sprint 1

## Objetivo

Construir la estructura inicial del proyecto RefugiPet y desarrollar las funcionalidades principales relacionadas con la autenticación de usuarios y el registro de mascotas.

## Duración

2 semanas

## Historias de Usuario

- HU-001 Registro de Usuario
- HU-002 Inicio de Sesión
- HU-006 Registrar Mascota

## Tareas

- Crear repositorio en GitHub.
- Configurar React.
- Configurar FastAPI.
- Crear base de datos PostgreSQL.
- Diseñar el DER.
- Implementar autenticación.
- Implementar CRUD de mascotas.

## Criterios de Finalización

- Las historias seleccionadas deben estar implementadas.
- La aplicación debe ejecutar correctamente.
- El código debe encontrarse en GitHub.
- La documentación debe estar actualizada.

## Resultado Esperado

Contar con una primera versión funcional del sistema que permita registrar usuarios, iniciar sesión y gestionar mascotas.
