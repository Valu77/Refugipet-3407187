# Diagrama de Proceso

## Descripción

El diagrama de proceso representa el flujo principal del sistema desde que un usuario ingresa a la plataforma hasta la finalización del proceso de adopción.

## Flujo principal

1. El usuario ingresa al sistema.
2. Se registra o inicia sesión.
3. Consulta las mascotas disponibles.
4. Aplica filtros de búsqueda.
5. Selecciona una mascota.
6. Envía una solicitud de adopción.
7. El refugio revisa la solicitud.
8. El refugio aprueba o rechaza la solicitud.
9. El usuario recibe la respuesta.

## Beneficios

- Facilita la comprensión del funcionamiento del sistema.
- Permite identificar cada etapa del proceso de adopción.
- Sirve como guía durante el desarrollo del proyecto.
