# Diagrama de Casos de Uso

## Descripción

El diagrama de casos de uso representa las funcionalidades principales del sistema RefugiPet y la interacción entre los diferentes actores con la plataforma.

## Actores

### Usuario

El usuario es la persona interesada en adoptar una mascota. Puede:

- Registrarse.
- Iniciar sesión.
- Consultar mascotas disponibles.
- Buscar mascotas mediante filtros.
- Enviar solicitudes de adopción.

### Refugio

El refugio administra las mascotas disponibles para adopción.

Sus funciones son:

- Registrar mascotas.
- Editar la información de las mascotas.
- Gestionar solicitudes de adopción.
- Actualizar el estado de las mascotas.

### Administrador

El administrador supervisa el funcionamiento del sistema.

Puede:

- Gestionar usuarios.
- Gestionar refugios.
- Supervisar las publicaciones.
- Controlar el acceso a la plataforma.

## Objetivo

Representar de manera gráfica las funcionalidades disponibles para cada tipo de usuario y la relación entre ellos.
